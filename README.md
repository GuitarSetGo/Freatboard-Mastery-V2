# [🎸 Fretboard Mastery v2.0](https://guitarsetgo.github.io/Freatboard-Mastery-V2/)

Guitar note trainer that runs in the browser. Practice identifying notes on the fretboard by clicking or playing directly with your guitar via microphone / audio interface.

## Stack

HTML · CSS · Vanilla JavaScript · Web Audio API

## Features

- 🎤 Real-time pitch detection via microphone or audio interface
- 🖱️ Click mode (no guitar needed)
- 3 difficulty levels: Explorer · Hero · Legend
- Live score, accuracy and progress tracking

## Usage

Just open `index.html` in your browser.

> For microphone access, use a local server or HTTPS (required by browsers).

```bash
npx serve .
